# Initial product proposals (archived)

These documents preserve the original v1 product, architecture, schema, screen,
permissions, pricing, and roadmap proposals. They are historical context only;
they are not current specifications and must not be used to implement behavior.

For current guidance, use:

- [`AGENTS.md`](../../../AGENTS.md) — hard engineering and domain rules.
- [`CONTEXT.md`](../../../CONTEXT.md) — canonical product vocabulary.
- [`docs/adr/`](../../adr/) — accepted decisions and amendments.
- [`docs/v2/`](../../v2/) — maintained implementation patterns; verify details
  against the current code and configuration.
- [`docs/roadmap/`](../../roadmap/) and GitHub Issues — planning and status.
- `packages/db/src/schema.ts` and `packages/db/migrations/` — database schema
  and migration source of truth.

The archived documents may contradict those current sources by design. Retain
them for historical traceability; do not link them as active requirements.
